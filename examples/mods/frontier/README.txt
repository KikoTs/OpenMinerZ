Frontier

A new world out to 25,000 blocks: redwood forests, salt flats and the ashlands, with their own blocks, landmarks, skies and music.

Scope: server
Version: 1.0.1

Enable in the main-menu Add-Ons screen before loading a world.
To edit, copy this folder into %LOCALAPPDATA%\OpenMinerZ\Mods first.
Validate with: openminerz_mod_sdk validate --strict <folder>
Test with: openminerz_mod_sdk run <folder> --seconds 10
Enable before creating a new world. Worlds made with this generator require it.
