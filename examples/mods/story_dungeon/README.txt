The Restless Crypt

A crypt under the hills, a hermit with a request, a three-stage quest, a dark crypt with torchlight, and a reward.

Scope: server
Version: 1.0.1

Enable in the main-menu Add-Ons screen before loading a world.
To edit, copy this folder into %LOCALAPPDATA%\OpenMinerZ\Mods first.
Validate with: openminerz_mod_sdk validate --strict <folder>
Test with: openminerz_mod_sdk run <folder> --seconds 10
