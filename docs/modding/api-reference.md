# OpenMinerZ modding API reference

API version 1. 288 functions in 43 libraries, 60 events, 0 constants.

> Generated by `openminerz_mod_sdk reference` from the registry the game itself builds
> (every area registered on stand-in backends). Do not edit: the CTest
> `openminerz_mod_sdk_reference` fails when this file no longer matches the code.
> Editor type definitions: `tools/ModSdk/types/openminerz.d.luau`; machine-readable:
> `tools/ModSdk/types/openminerz-api.json`.

How to read an entry:

- **Runs on** is the VM the function exists on. Calling it on the other side raises
  "... is only available on the server" (or client).
- **Needs** is the capability the calling mod must have. Client mods get `presentation`,
  `local_storage` and `query`. Server mods get `gameplay`, `network`, `world_storage`, `query`
  on the server VM and `presentation`, `local_storage`, `network`, `query` on the client VM.
- **Usable by** spells that out: which kinds of mod can call it, and from which VM.
- `vector` is Luau's native vector (`vector.create(x, y, z)`); a vector parameter also takes
  `{x = , y = , z = }`. `Handle` is an engine object (`.kind`, `.id`). `table` is a table with
  string keys, `array` a list. A `?` marks an optional parameter.

See [authoring.md](authoring.md) for sides and capabilities, and the guides for worked examples.

## ai

### ai.attack

```luau
ai.attack(entity: Handle, attack: string, target: Handle?) -> boolean
```

Starts one of the creature's attacks (creatures.define{attacks = {...}}) at a target (default: its own). The attack's animation starts now on every client and the hit is decided `windup` seconds later: melee strikes what is still within reach and arc, ranged fires its projectile. False when the attack is cooling down, out of range, or another one is under way.

**Runs on:** server · **Needs:** gameplay · **Usable by:** server mods (server VM)

| Parameter | Type | Description |
|---|---|---|
| `entity` | `Handle` | An entity whose creature has AI. |
| `attack` | `string` | Attack name. |
| `target` | `Handle` (optional) | Player or entity. |

**Returns** `boolean`: Whether it started.

## brains

### brains.define

```luau
brains.define(name: string, definition: table) -> string
```

Defines a brain: a state machine creatures run on the server (creatures.define{brain = name}). `states` maps each state's name to {enter, tick, exit, damaged, heard, noticed} callbacks, each called as (entity, info); `tick` (and the others) may return the name of the state to switch to. A state may also be just a function (its tick). `initial` is the first state (default: the first one). info = {dt, state, time (seconds in this state), target, target_position, target_distance, sees_target, health, max_health, health_fraction, position, home, home_distance, pack_size, pack_hurt (0..1 of the pack's health lost), leader, phase, attacking, known, heard (where it last heard something), data}; damaged adds amount and attacker, heard adds noise, noticed adds noticed.

**Runs on:** server and client · **Needs:** nothing · **Usable by:** client mods, server mods (both VMs)

| Parameter | Type | Description |
|---|---|---|
| `name` | `string` | Short name or "mod:name". |
| `definition` | `table` | {initial, states} |

**Returns** `string`: The full key.
